## コーディング規約

コードを書く・直す・レビューする前、および実装計画を作る前に、必ず `$coding-standards` skill を読み込み、その規約に従う。
このファイルには、規約に対するこのプロダクト固有の差分だけを書く。

## コマンド

| 用途 | コマンド |
|---|---|
| lint / format の検査 | `pnpm biome ci .` |
| 型チェック | `pnpm -r typecheck` |
| テスト（全体） | `pnpm -r test -- --bail 1` |
| テスト（1 ファイル） | `pnpm vitest run <file>` |
| カバレッジ | `pnpm -r test:coverage`（閾値 100%） |

コードを変更したら、完了と報告する前に lint・型チェック・変更したファイルのテストを実行する。
